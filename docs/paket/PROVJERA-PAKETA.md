# Provjera paketa

- 11 originalnih fotografija vrata i originalni mali logo, preuzetih iz Maderinog profila.
- Dvije ambijentalne hero ilustracije i jedna referenca odabranog izgleda.
- Svi slikovni formati otvoreni i provjereni; dimenzije odgovaraju manifestu.
- Svaka od 11 ponuda ima postojeću sliku i izvor objave.
- Potvrđeno šest imenovanih modela; pet zapisa su opisne posebne izvedbe.
- Sve navedene lokalne putanje dokumentacije postoje.
- JSON datoteke su valjane; nepoznate cijene, proizvodne mjere i 3D modeli nisu izmišljeni.
- SHA-256 oznake slikovnih datoteka nalaze se u manifestu.

Ovo je pripremljen i provjeren paket za implementaciju. Web aplikacija, njena funkcionalnost i testovi izvode se u Claude Codeu prema superpromptu. Paket ne sadrži gotovu web aplikaciju ili proizvodne GLB datoteke.
